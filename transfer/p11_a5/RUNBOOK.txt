P11-A5  REAL WINDOWS LOCAL VALIDATION  (repo-external; do not commit a5.py or this file)
=========================================================================================

What this validates: real P9 private root -> frozen P10 governed view -> P11 A1 adapter -> P11 A2 loopback server
-> P11 A3/A4 PWA shell -> real browser, while proving both roots stay read-only, zero outbound network, no J-Quants,
no private browser persistence, no API caching, explicit PIT only, stale data cleared, offline shell only, repo unchanged.

Paste back ONLY the lines that start with "REPORT:". Never paste anything else from the screen or from D:\p11_a5_work.

0. One-time setup (one PowerShell window; keep it for everything)
------------------------------------------------------------------
    cd <your daily-market-brief checkout>
    git fetch origin claude/investment-intelligence-phase6
    git checkout claude/investment-intelligence-phase6
    git merge --ff-only origin/claude/investment-intelligence-phase6
    git rev-parse HEAD            # must print 43c0b856d41efed397de213a1a06178c5e97ab10
    Remove-Item Env:JQUANTS_API_KEY -ErrorAction SilentlyContinue
    New-Item -ItemType Directory -Force D:\p11_a5_work | Out-Null
    # copy a5.py into D:\p11_a5_work\a5.py
    Test-Path D:\p9_a5_private    # must print True  (real P9 root; READ ONLY)
    Test-Path D:\p10_a5_private   # must print True  (real P10 root from P10-A5; READ ONLY)

Browser automation: the helper drives the installed Microsoft Edge or Google Chrome itself over the DevTools protocol
(Python standard library only; nothing is installed). It looks for msedge.exe / chrome.exe in the usual Program Files
locations, or uses the executable in the environment variable P11_A5_BROWSER. The browser runs headless with a fresh
validation-only profile under D:\p11_a5_work\browser_profile and listens for the DevTools protocol on 127.0.0.1 only;
your normal browser profile is never touched. Add --headed to any browser stage to watch it. Only if no browser executable
exists at all does the helper fall back to a short manual checklist (y/n questions) and print MANUAL_PATH.

1. Stages (run in order; each prints REPORT lines only and stops on the first failure)
--------------------------------------------------------------------------------------
    # | Command                                                                            | Expected final line
    0 | python D:\p11_a5_work\a5.py preflight --repo <checkout path>                       | STAGE_PASS preflight
    1 | python D:\p11_a5_work\a5.py read --at <AT> --as-of-date <DATE>                     | STAGE_PASS read
    2 | python D:\p11_a5_work\a5.py server                                                 | STAGE_PASS server
    3 | python D:\p11_a5_work\a5.py browser                                                | STAGE_PASS browser
    4 | python D:\p11_a5_work\a5.py storage                                                | STAGE_PASS storage
    5 | python D:\p11_a5_work\a5.py offline                                                | STAGE_PASS offline
    6 | python D:\p11_a5_work\a5.py restart                                                | STAGE_PASS restart
    7 | python D:\p11_a5_work\a5.py verify                                                 | A5_PASS then STAGE_PASS verify

<AT>   = one explicit aware instant you choose, e.g. 2026-10-18T09:00:00+09:00 (no clock is used; it must be LATER than
         the P10-A5 authority instants, i.e. later than the base instant you used in P10-A5).
<DATE> = the review reference date you choose, e.g. 2026-10-18.
Do not paste <AT> or <DATE> back. They are bound once; re-running `read` with different values is refused (PIT_ALREADY_BOUND).

3. If a stage fails
-------------------
- Paste the REPORT lines only (they contain safe codes; FAILED_TEST lines name repo tests that run on synthetic data).
- Do not delete, edit or "fix" D:\p9_a5_private, D:\p10_a5_private or D:\p11_a5_work; do not send their contents.
- Every stage may be re-run after the supervisor's decision. FAIL P9_MUTATED / P10_MUTATED means a root changed since
  preflight: STOP and report; the helper never repairs anything.
- FAIL CREDENTIAL_PRESENT_UNSET_IT_AND_RERUN: run Remove-Item Env:JQUANTS_API_KEY in this window and re-run the stage.
- FAIL BROWSER_UNAVAILABLE / BROWSER_DEVTOOLS_TIMEOUT / BROWSER_EXITED_EARLY: no Edge / Chrome was found, or it could not
  be started headless. Set $env:P11_A5_BROWSER to the full path of msedge.exe or chrome.exe and re-run the stage; report
  the result. The manual checklist is a last resort used automatically only when no browser executable exists at all.
  Always report the BROWSER_PATH / MANUAL_PATH line.
