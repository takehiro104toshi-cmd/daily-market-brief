## 1. Compass Philosophy（羅針盤の思想）

観測から帰納される設計思想（CONFIRMED）:

1. **結論先行・根拠必置**: 毎日3行の結論（●ボレット）を先に出し、本文で「なぜそう考えるのか」を必ず展開する。根拠なき結論・結論なき解説は存在しない。
2. **比較で判断する**: 単一指標で結論しない。「米国株安×先物横ばい」「金利上昇×割安金融」「指数上昇×物色の偏り」のように、常に2つ以上の材料の掛け合わせで判定する。
3. **短期と長期の分業**: 当日の見通し（需給・イベント駆動）と中長期テーマ（構造・業績駆動）を紙面レベルで分離し、混ぜない。ただし「長期ストーリー不変→短期の下落は押し目」という一方向の接続だけは許す。
4. **テーマは供給網まで降ろす**: テーマ論は必ず「ボトルネック→解決技術→供給網の各層→シェアを持つ個別銘柄（コード付き）」まで具体化する。
5. **反対材料の常設**: どんな強気にも「もっとも/他方」で逆風・監視条件を併記する。
6. **出典の階層管理**: 一次情報＞市場データ＞伝聞を文法レベルで書き分け、図表は出所・基準日・算出条件を必ず付す。
7. **読者への行動接続**: 最終的に営業員が顧客に話せる形（注目銘柄・レーティング・セミナー導線）まで落とし込む。情報は行動可能単位で終わる。

## 2. Daily Analysis Flow（毎朝の分析フロー・復元版）

紙面の依存関係から復元した制作フロー（LIKELY。順序はHYPOTHESISを含む）:

```
(1) 前夜データ確定    … 米3指数・セクター騰落・金利・商品・VIX/MOVE・要人発言を収集
(2) 朝7時スナップ     … ドル円（東京7時）・夜間日経先物を取得
(3) 市場レジーム判定   … リスクオン/オフ、物色の偏り、過熱度（MA乖離）を更新
(4) 本日の方向仮説    … 先物アンカー＋織り込み度＋イベント距離で当日シナリオ作成
(5) 物色テーマ選定    … 発火点（政策/決算/価格/技術）から本日の1〜2テーマを選ぶ
(6) 銘柄への展開     … テーマ→供給網→シェア企業→業績データで裏取り
(7) 図表選定       … 当日の主張を最も支える1点をP1に配置
(8) 週次レイヤー     … 月曜のみ: 先週の物色実績（ETF・業種・自社フロー）を集計し週間見通しへ
(9) 検証レイヤー     … 過去の主張の追跡（例: 裾野拡大は数日間継続して点検される）
```

## 3. Information Hierarchy（情報の優先順位）

観測された引用頻度・配置から（CONFIRMED）:

1. 価格・需給の実データ（CORE 10指標＋夜間先物）— 毎日の判断の一次入力
2. イベント・要人発言（日付付きFACT）— 方向転換のトリガー
3. 企業の業績・受注・計画（会社発表）— テーマ・銘柄の裏付け
4. 政策文書・投資金額 — 中期テーマの発火点
5. 市場予想・コンセンサス（QUICK・LSEG）— 期待値とのギャップ測定
6. 伝聞・報道 — 弱いFACTとして文法で減衰させて利用

## 4. Market Data Hierarchy

`MARKET_DATA_TAXONOMY.md` 参照。要点:
- **CORE**（毎朝固定10指標）: 日経平均/25日MA乖離/TOPIX/プライム売買代金/NYダウ/S&P500/ナスダック/日米10年金利/ドル円(朝7時)
- **SUPPORT**（毎朝固定約30系列）: 米11セクター（前日比降順）/主要7カ国指数/CRB・金・WTI/ラッセル2000・SOX・VIX・MOVE/日米バリュー・グロース
- **CONTEXT**（オンデマンド）: 売買代金占有率・寄与度・日中値幅・MA乖離・SOX相関・予想EPS・PER/PEG・季節性チャート等
- 指標ごとに差分表現（%/％pt/額/乖離率）が設計されている点が本質。

## 5. News Selection（ニュース選択）

P2「要人発言・イベント等」の採録基準（帰納、LIKELY）:
1. 金融政策（FOMC/日銀/ECB/英中銀/新興国中銀）
2. 政権・財政・規制（トランプ発言、税制、骨太、選挙）
3. 地政学（中東停戦・違反・協議の進捗）
4. 主要統計（PMI/PCE/雇用/GDP/CPI/求人）
5. 市場の節目（円が○年ぶり水準、等の記録更新）
- 1日4〜6本に厳選。すべて（主体 日付）付き。市場に接続しないニュースは載らない。
- 銘柄ニュース（決算・増産・提携）はP2でなく、P1テーマまたは銘柄面で「因果の中」に置かれる。

## 6. Market Regime Analysis（相場環境認識）

レジームを構成する観測変数（CONFIRMED）:
- リスク選好: VIX/MOVE、地政学の距離、リスクオン語彙（「買戻し」「リスクオン姿勢」）
- 過熱度: 25日/200日MA乖離、急上昇後の「利益確定売り」語彙
- 物色の質: 売買代金占有率、寄与度の顔ぶれ、裾野拡大の有無
- 金利レジーム: 利上げ/据え置き観測、ドットチャート、日米金利差
- 需給カレンダー: 配当再投資、総会、四半期末、連休、SQ的イベント
- レジーム転換は「イベント通過」（中銀会合一巡→関心は業績・テーマへ）で明示的に宣言される（6/18）。

## 7. Short-Term Forecast Logic（短期予測ロジック）

`ANALYSIS_RULE_CATALOG.md` A〜D群参照。核となる決定木（CONFIRMED）:
```
夜間先物の水準（最優先アンカー）
→ 前夜米国（3指数・SOX）との整合チェック（乖離すれば「織り込み済み」判定）
→ イベント距離（決算・統計・連休が近いか）で振れ幅を調整
→ 過熱度（MA乖離）で押し目メドを設定
→ 結論: 方向（堅調/底堅い/一進一退/利食い優勢/反落）＋条件（〜次第）＋物色テーマ
```
- 予測は「方向＋メカニズム＋無効化条件」の3点セットで出す。指数の数値予想はしない（節目参照のみ）。為替のみ数値レンジ必須。

## 8. Sector Rotation Logic（セクターローテーション）

`ANALYSIS_RULE_CATALOG.md` E群参照。要点:
1. 主役テーマ（AI）は否定しない。資金の「波及先」を予測する（循環物色: 電線→装置→材料→部品→サブシステム→化学）。
2. 出遅れセクターは「出遅れ×新規カタリスト」の交差でのみ推奨（政策・再編・金利・決算）。
3. 米国はセクター相対PER（10年±1σ）で割安層を特定し、マクロ追い風（金利→金融）と掛け合わせる。
4. スタイル（V/G）は金利と季節性（配当再投資）で判定。
5. 週次のテーマ型ETF騰落で回転の実績を検証する（先週/先々週の2期比較）。

## 9. Theme Discovery Logic（テーマ発見）

`THEME_DISCOVERY_RULES.md` 参照。要点:
- 発火点7類型（政策/中核企業決算/技術ボトルネック/価格/地政学/人口動態/取材）。
- 展開は「需要起点→ボトルネック→解決技術→供給網分解→シェア企業→数値裏付け→リスク」の7段。
- 「期初計画にない受注」（フジクラ型）が最強のEmergingシグナル。
- AI一色の局面でも対極（ディフェンシブ・体験消費）を意図的に供給する。

## 10. Stock Selection Logic（銘柄選択）

`ANALYSIS_RULE_CATALOG.md` F群参照。要点:
- 根拠は11タイプ（シェア/受注/計画・修正/政策/供給網位置/割安/還元/金利感応/ディフェンシブ/需給イベント/テクニカル）。1銘柄に2〜3タイプを複合させる。
- 必ず「事業説明（何で稼ぐ会社か）→ 成長ドライバー（なぜ今か）」の2段で書く。
- 定量の裏付け（増益率・受注残・シェア・目標株価）と時間軸を必ず付す。
- アナリストレーティング（目標株価付き）とストラテジスト推奨を別枠で区別する。

## 11. Long-Term Narrative Logic（長期ナラティブ）

グローバル投資アイデア面の構造（CONFIRMED）:
```
現在の事実（決算・政策・価格）
→ 構造変化の指摘（AI実装、脱炭素、人口動態、国内回帰）
→ ボトルネック／制約
→ 恩恵の連鎖（一次→二次→三次受益）
→ 具体企業（財務・受注・シェアで裏付け）
→ 留保（短期寄与は限定的、等の時間軸注意）
```
- 長期論に短期の値動きを持ち込まない。逆に、長期ストーリーの「不変」確認が短期の押し目買い判断の根拠になる（一方向接続）。

## 12. Chart Selection（チャート選択）

P1は必ず1点、アイデア面は1〜3点。観測された目的別分類（CONFIRMED）:

| 目的 | チャート型 | 実例 |
|---|---|---|
| TREND | 指数化した価格比較（基準日=100） | 日経平均vs半導体指数（6/23）、S&P500vsJBL（6/24） |
| CONFIRMATION | 予想EPS・受注・売上の推移 | 予想EPS（6/19）、ダイフク受注（6/22）、SCI受注残（6/18） |
| CAUSAL SUPPORT | 相関係数・2軸比較 | SOX相関（6/26）、WTIvsナフサ（6/18）、ガソリン価格（7/1） |
| SEASONALITY | 日次分布の棒グラフ | 配当支払社数（6/22）、総会集中率（6/25） |
| VALUATION | PER/イールドレシオ±1σバンド | 6/23の4面 |
| SCREENING | 条件抽出の結果表 | PEG13銘柄（6/29）、TOPIX500上昇率（7/1）、寄与度（6/24） |
| MARKET SIZE | 市場規模予測棒グラフ | テスタ（6/19）、HDD（6/25）、水素（6/22） |

選定原則: 「その日の主張を1枚で支えるもの」を選ぶ。装飾目的のチャートは存在しない。全図表に出所・基準日・算出条件。

## 13. Fact / Analysis / Forecast Separation

`FACT_ANALYSIS_FORECAST_SPEC.md` 参照。要点:
- 文単位で三態が語尾から判別可能（〜した/〜とみられる/〜となろう）。
- 伝聞FACTは「〜と伝わる/一部報道/もよう」で減衰。
- 段落は FACT→ANALYSIS→FORECAST の順に流れる。
- 予測は6段階の語彙ラダーで確信度を表現（投資妙味＞想定する＞期待＞注目＞可能性＞条件付き）。

## 14. Evidence Requirements（根拠の要件）

- 図表: 出所＋作成者＋基準日＋算出条件の4点（CONFIRMED・全図表）。
- 要人発言: （発言者 日付）（CONFIRMED・全件）。
- 予想値: 予想主体（会社計画/市場予想/岡三予想）を明記（CONFIRMED）。
- 銘柄: コード必須、レーティングは終値・目標株価・日付付き（CONFIRMED）。
- 数値の加工: 乖離率・変化幅・単純平均等の定義を脚注化（CONFIRMED）。

## 15. Morning Report Structure（朝レポートの構造）

`REPORT_STRUCTURE_SPEC.md` 参照。骨子:
- 7:30発行。P1=日本株（本日/今週）、P2=米株⇄為替（月水金/火木）＋指数表＋要人発言、P3=長期アイデア、P4=注目日本株＋レーティング、月曜のみ先週レビュー2面、最終面=資料導線。
- 「3行結論→根拠→データ→銘柄→行動」の順に薄く読める設計。30秒で3行、3分でP1、全読で5〜7ページという多段読解に対応している（本プロジェクトのMorning Brief 3段階構想と同型）。

## 16. Failure Modes（想定される失敗モードと羅針盤の防御）

| 失敗モード | 羅針盤の防御機構 |
|---|---|
| 単一指標への過剰反応 | 常に複数指標の掛け合わせで判定（§1-2） |
| イベント跨ぎの断定 | イベント前は方向を保留し「次第では」で分岐（JP-DIR-004） |
| テーマの過熱追随 | MA乖離・PER/PEG・占有率で過熱を毎日定量監視（JP-INT-001/003） |
| 根拠不明の数字 | 出典4点セットの強制、伝聞の文法減衰（§14） |
| 短期と長期の混同 | 紙面分離＋時間軸語彙の使い分け（JP-TIME-001/002） |
| 強気一辺倒 | 反対材料・負の側面の常設（JP-RISK-001/002） |
| 予測の検証不能 | 為替はレンジ明示、株は無効化条件明示（§7）。ただし的中検証の紙面は未観測→Phase 5で補完すべきギャップ |

## 17. Automation Implications（自動化への示唆）

Phase 1以降の設計に直結する結論:

1. **データ層**: CORE/SUPPORT/CONTEXTの3層データモデル。指標メタデータに差分表現・単位・基準時刻を持つ（Phase 2 Data Bank schema の骨格）。
2. **Evidence層**: statement_type・source_tier・as_of・forecast_confidence・forecast_agent・counter_points を持つ文単位モデル（Phase 1）。
3. **ルール層**: 本カタログのルールは「条件（指標の状態の組）→含意（方向・セクター）→確信度」の形で表現可能。`analysis_rules/market_rules.yaml` にサンプル実装。LLMはルールの適用と文章化を担い、ルール自体は宣言的に管理する。
4. **テーマ層**: テーマ＝グラフ（需要起点→ボトルネック→技術→供給網→銘柄）。ノードに数値裏付け（市場規模・受注）を添付（Phase 6 Theme Map schema の骨格）。
5. **時間軸層**: すべての出力に horizon タグ（intraday/1d/1w/medium/long）を必須化。
6. **検証層**: 羅針盤に無い「予測の翌日検証」はPhase 5（Prediction Journal）で本システム独自の優位性になる。為替レンジ・方向予測・注目銘柄の追跡が検証対象として定義しやすい。
7. **人格層**: 執筆者ローテーション（日本株/米株/為替/アイデアの専門分担）は、生成システムでは「セクション別プロンプト人格」として再現可能（HYPOTHESIS）。
