## 2. 展開アルゴリズム: 一次テーマ → 供給網 → 銘柄（CONFIRMED）

観測された共通パターンを一般化すると:

```
① 需要の起点を特定        （AI利用拡大、脱炭素、防衛費、復興…）
② 物理的な制約・ボトルネックを特定 （電力、通信容量、熱、記録密度、人手、後工程…）
③ 制約を解く技術・製品を特定    （SMR、光通信、HAMR、アンモニア、FA/ロボット…）
④ その製品の供給網を分解      （素材→部材→装置→計測→施工→運用）
⑤ 各層で「シェア・技術優位を持つ企業」を named list 化（コード付き）
⑥ 業績・受注の実データで需要の実在を確認（決算・受注残・増産発表）
⑦ リスク・負の側面を付記
```

## 4. 展開の質を担保する道具（CONFIRMED）

1. **数値による需要の実在確認**: 市場規模予測チャート（半導体テスタ 6/19、HDD 6/25、水素 6/22）、増産倍率（InP 7-10倍）、会社目標（TDK AI向け10倍、パナHD蓄電9,500億円）。
2. **供給網の層ごとの「シェア」明記**: ほぼ全銘柄に「世界シェアトップ」「2強」「世界初」等の競争地位を付す。
3. **一次受益と二次受益の区別**: 装置本体（一次）だけでなく消耗品・制御機器・計測（二次）へ意識的に広げる（6/26 サブシステム）。
4. **テーマ×出遅れのクロス**: テーマ内で株価が過熱した銘柄群から、同テーマでバリュエーションの低い層（化学・後工程・サブシステム）へ資金がローテーションすると想定（6/26, 6/30）。
5. **テーマ型ETFによる週次の定点観測**: 月曜面で8テーマ（ロボティクス&AI/半導体/レジャー&エンタメ/新成長インフラ/高配当30/銀行高配当/防衛テック）の資金流入を先週・先々週比較（6/22, 6/29）→ テーマの勢いの変化率を観測する仕組みが常設されている。

## 5. Emerging Theme 検出の実装示唆（Architecture Recommendation）

羅針盤の運用から逆算すると、Emerging Theme検出には以下の信号が有効:
- 政策文書・予算金額の新規出現（T1）
- 中核企業の想定外の受注・増産・上方修正（T2）: 「期初計画にない受注」が最強シグナル（6/19 フジクラ）
- 「限界」「不足」「逼迫」語彙の技術ニュース（T3）
- テーマ型バスケットの騰落率の週次変化（§4-5）
- テーマ内バリュエーション分散の拡大（過熱層と出遅れ層の分離）

## 6. 禁止事項（羅針盤が「やっていない」こと）

- 根拠となる発火点なしのテーマ提示（全テーマ記事に §1 の発火点が存在する）。
- 銘柄名なしのテーマ論・テーマ名なしの銘柄推奨（必ず両方セット）。
- 二次受益の飛躍（連鎖の各ステップに技術的因果の説明が挟まる）。
