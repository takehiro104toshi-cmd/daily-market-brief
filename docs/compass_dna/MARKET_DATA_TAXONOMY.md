# MARKET_DATA_TAXONOMY — 羅針盤が毎朝見る市場データの分類

Phase 0（Compass DNA解析）成果物。対象: 2026/06/18〜07/01 の10冊。

分類:
- **CORE** … 毎号ヘッダーに固定掲載。相場観の起点となる一次データ。
- **SUPPORT** … 毎号P2テーブルに固定掲載。セクター・国際・需給・スタイルの文脈データ。
- **CONTEXT** … 固定枠ではないが、論点に応じて本文・図表で繰り返し参照される派生指標。

## 1. CORE — P1ヘッダーテーブル（CONFIRMED: 全10号で同一10列）

| # | 指標 | 掲載値 | 「前日比」の定義 | 備考 |
|---|---|---|---|---|
| 1 | 日経平均 | 終値 | % | 相場観の主軸 |
| 2 | 日経平均25日MA | 水準 | **日経平均との乖離率（%）** | 前日比欄が乖離率になっている点が最大の特徴。過熱/押し目測定器 |

| 4 | プライム売買代金（兆円） | 当日値 | **前日比変化額（兆円）** | エネルギー（商い）の量。水準と増減の両方を見る |
| 5 | NYダウ | 終値 | % | 前夜の米国 |

| 7 | ナスダック | 終値 | % | 同上（ハイテク） |

| 9 | 米10年国債利回り | 終値 | **変化幅（%pt）** | FRB・バリュエーションの文脈 |

設計上の含意:
- 株価指数は率、金利・為替は幅、売買代金は額、25日MAは乖離率——**指標ごとに意思決定に効く差分表現を選んでいる**。
- ドル円だけ朝7時値である＝「昨日の終値」ではなく「今この瞬間」の外部環境を1点だけ取り込む。

## 2. SUPPORT — P2「主な株価・市況関連指数」（CONFIRMED: 全10号で同一構成）

### 2.1 米国セクター別騰落率（S&P500の11セクター）
資本財 / 金融 / 情報技術 / エネルギー / 公益事業 / 素材 / ヘルスケア / 生活必需品 / 不動産 / 一般消費財 / コミュニケーション
- 各: 終値・前日比%・年初来%。**前日比降順ソートで掲載**（並び順自体が情報）。

### 2.2 国別株価指数
上海総合 / 香港ハンセン / 台湾加権 / 英FTSE100 / 独DAX / 印センセックス / 伯ボベスパ
- アジアの半導体経済圏（台湾・韓国株は本文で補完）と欧州・新興国を最小セットで俯瞰。

### 2.3 商品市況
CRB指数 / 金先物 / WTI原油先物
- 原油はコスト・インフレ・中東情勢の代理変数として本文で最頻出。

### 2.4 米国その他指数
ラッセル2000（中小型） / **SOX**（半導体） / **VIX**（株ボラ） / **MOVE**（債券ボラ）
- SOXは日本株予測の最重要外部変数（`ANALYSIS_RULE_CATALOG.md` JP-US-002）。
- VIXとMOVEをペアで見る＝株と債券のリスク認識のズレを検出。

### 2.5 V/G（スタイル）
TOPIXバリュー / TOPIXグロース / ラッセル1000バリュー / ラッセル1000グロース
- 日米それぞれのバリュー/グロース優劣を毎日追跡。金利局面・配当再投資季節性の判定材料。

### 2.6 要人発言・イベント等（テキストデータ）
- 前営業日の中銀・政府・地政学・主要統計ヘッドライン4〜6本。（発言者 日付）形式の出典付き。
- FACTの供給源であり、P1/P2見通しの根拠として引用される。

## 4. 自動化への示唆（Architecture Recommendation）

1. CORE 10指標＋SUPPORT約30系列は毎日固定取得・固定表示（欠測は「Closed」明示）。
2. 差分表現（%/％pt/額/乖離率）を指標メタデータとして保持すること。
3. CONTEXT指標は「ルール（`ANALYSIS_RULE_CATALOG.md`）が発火した時に呼び出される」オンデマンド系列としてモデル化できる。
4. 「岡三の買付上位」に相当するものは個人システムでは「ユーザーの閲覧・Watchlist行動」が代替候補（Phase 10 Personal Intelligenceに接続）。
