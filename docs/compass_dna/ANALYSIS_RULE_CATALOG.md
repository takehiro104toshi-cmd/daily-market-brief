- 判定: 米国株の方向と先物水準が食い違う場合、**先物を優先**して当日レンジを推定する（例: 米国株安でも先物がほぼ前日水準→「底堅い」。米国株まちまちでも先物73,000円近辺→「強い地合い継続」）。

### JP-DIR-003: 織り込み済み判定

- 判定: 織り込み済みなら反応は限定的とみなす（例: 米国株高でも「事前に織り込んでいた部分もある」）。

### JP-DIR-004: イベント前は手控え、イベント後はアク抜け
- 条件: 主要イベント（大型決算・FOMC・雇用統計・連休）まで1〜2営業日
- 判定: イベント前=利益確定・買い手控え・様子見を想定。イベント通過で（結果が悪くなければ）アク抜け・買い戻しを想定。

### JP-DIR-005: 急落日のプロトコル
- 条件: 日経平均が大幅下落（例: -3.55%）した翌朝
- 手順: ①下落率と主因（例: SOX -7.9%）を定量提示 → ②押し目メドをテクニカルで示す（25日MA水準を明記）→ ③過去の類似局面（5月・6月は25日MA近辺から切り返し）を参照 → ④長期ストーリー不変なら「押し目買いの好機」と再フレーム → ⑤主役銘柄の入れ替わり（寄与度）で相場の健全性を点検。
- Confidence: CONFIRMED（大幅安は1回だが、押し目買い再フレームは全期間で反復）
- Evidence: 6/24 P1（全手順）, 6/25 P1, 6/26 P1, 6/30 P1（「下落局面では押し目を拾うスタンス」）

## G. 時間軸の運用（Time Horizon）

### JP-TIME-001: 時間軸語彙の使い分け
- 「本日」= 当日1日 / 「目先」「当面」= 数日〜数週 / 「今週」= 月曜の週間見通し / 「中長期」= 数年（テーマ・構造）。
- 判定: 短期の悪材料と長期ストーリーを**同一文中で明示的に分離**する（例:「短期的な業績への寄与は限定的なものの、将来的な成長が期待されよう」「目先は波乱含みでも、中長期的な押し目買いの好機」）。
- Confidence: CONFIRMED
- Evidence: 6/19 P4（アドバンテスト シリコンフォトニクス）, 6/29 P3（PEG）, 6/30 P1, 6/24 P2

### JP-TIME-002: 短期=需給・イベント、長期=構造・業績で説明を分業
- 短期結論の根拠は需給（先物・過熱・裾野・期末）とイベント。長期結論の根拠は市場規模予測・政策・技術・人口動態。両者を混ぜない。
- Confidence: CONFIRMED
- Evidence: 全号のP1（短期）とアイデア面（長期）の役割分担そのもの
