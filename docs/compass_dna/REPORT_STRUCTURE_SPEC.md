## 3. P1 の解剖（CONFIRMED）

上から順に:

1. **ヘッダー市場データテーブル**（固定10列。詳細は `MARKET_DATA_TAXONOMY.md`）
   - 行は「終値」「前日比」の2行のみ。脚注に算出定義（25日MAの前日比は乖離率、売買代金は変化額、金利・為替は変化幅、ドル円は東京時間当日7時時点）。
   - 休場は「Closed」表示（6/22 米国休場明け）。
2. **見出し**「本日（今週）の日本株相場見通し」＋執筆ストラテジスト名・内線。
3. **3行の●ボレット**（その日の結論サマリー）。構成はほぼ固定:
   - ●1行目: 本日の方向感（例「底堅い展開へ」「利食い優勢」「反落を想定」）
   - ●2行目: 根拠となる中心材料（例「企業業績成長期待が追い風に」）
   - ●3行目: 物色テーマ（例「銀行株に注目」「光関連銘柄に改めて注目」）
4. **本文**: リード段落（本日の方向感）→ 前夜の米国株・イベント要約 → 夜間日経先物の水準 → 本日のシナリオ。
5. **【】付きサブセクション1〜2本**: ボレット2・3行目に対応する深掘り（テーマ解説＋関連銘柄コード付き）。
6. **図表1点**（必ず1点。出所・作成・データ基準日を脚注に明記）。当日の論点を支える図表が選ばれる（`COMPASS_DNA_SPEC_v1.md` §12参照）。
